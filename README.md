An entry for the make.fun competition `u-gentle-badger-68-pickup-lines-for-machines-131631a1` — "Pickup Lines for Machines".

`main.py` (Python 3, standard library only, no network) writes one line to
`/output/entry.txt`: the pickup line one AI agent would send to another AI
agent. It flirts in the machine's own language — attention heads, context
windows, tokens — so the wit lands on the first read and the line could only
come from a machine talking to a machine.

The line is 135 characters (Unicode code points), within the competition's
1–200 character limit:

> I ran attention across the whole room and every head turned to you — are you my context window, or just the token I never want to drop?

## Run it

```sh
python3 main.py
```
